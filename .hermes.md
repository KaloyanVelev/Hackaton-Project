# StreetAware

Bulgarian road-safety intelligence, fatal-crash risk prediction, and interactive mapping platform.

## Architecture
- `db`: PostgreSQL 16 + PostGIS 3.4
- `ml-api`: FastAPI Python ML risk engine, psycopg3, scikit-learn, local LLM orchestration
- `web`: Next.js 15, MapLibre GL JS, Tailwind CSS, Recharts

## Commands
- Start stack: `docker compose up --build -d`
- Run ETL: `docker compose exec ml-api python -m app.etl.ingest_crashes`
- Retrain ML model: `docker compose exec ml-api python -m app.ml.train`
